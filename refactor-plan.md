## 5. Risks & Watch-outs

- **R1 — Rollback-only saat recovery balapan `Idempotency-Key`.** Memindahkan `@Transactional` ke
  service tanpa memisahkan bean akan membuat `PersistenceException` dari `flush()` menandai transaksi
  *rollback-only*, sehingga `findReused()` setelahnya gagal (`Transaction marked as rollback only`).
  Mitigasi: bean transaksional khusus (`InventoryMutationService`, berisi `@Transactional applyStockIn/
  applyStockOut`) dipanggil oleh orchestrator `InventoryService` yang **tidak** transaksional —
  exception lolos keluar boundary, transaksi di-rollback, lalu lookup pemenang dijalankan pada
  transaksi baru. Perilaku `StockMutationApiTest` (balapan) dan `StockMutationAtomicityTest` harus
  tetap hijau.
- **R2 — `quarkus.hibernate-orm.schema-management.strategy=validate`.** Setiap anotasi entity yang
  menambah kolom (mis. `@Version`) memerlukan migrasi Flyway baru; tanpa itu startup gagal.
- **R3 — Kontrak API beku.** Envelope, nama field, status 201/200, `Idempotency-Key`, dan header
  `X-Correlation-Id` tidak boleh berubah. `ApiResponse` tetap `record(success, message, data)`.
- **R4 — `docs/design-system.md` adalah dokumen sumber** yang diedit tangan; `docs/stockflow-design.md`
  adalah hasil generate — jangan diedit tangan, regenerasi via script ekspor.
- **R5 — Test memerlukan Docker** (Dev Services PostgreSQL sekali pakai). Docker 29.8.2 tersedia.
- **R6 — Bash minimal di mesin ini** (tanpa `sed`, `grep`, `wc`, `python3`, `date`): script bundle skill
  tidak dapat dijalankan; verifikasi manual memakai tool pencarian internal. Semua check yang tidak
  dapat dijalankan dicatat `SKIPPED — <reason>`, tidak pernah difabrikasi PASS.
- **R7 — `StockMutationRepository` dibubarkan** (P10/P11). Orkestrasinya pindah ke service; memastikan
  tidak ada pemanggil lain (hanya `InventoryService`) dan 13 test tetap lulus.
- **R8 — Urutan P10/P11 saling terkait** (transaksi & repository interface). Eksekusi bertahap dengan
  compile hijau di setiap langkah; jangan menggabungkan keduanya dalam satu edit besar.
